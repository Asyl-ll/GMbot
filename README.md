# Бот-напоминалка (Telegram)

Ты пишешь боту задачу с датой («завтра сдать отчёт», «25.11 купить билеты», «пт встреча»),
а каждое утро в 8:00 (Астана) он присылает погоду, задачи на сегодня, просроченные и ближайшие 3 дня.
Расписание универа добавляется в `schedule.py`.

## Как это устроено
- Бот работает через webhook (FastAPI + python-telegram-bot).
- Задачи хранятся во внешней Postgres-базе, потому что диск на бесплатном Render не сохраняется.
- Бесплатный Render засыпает без трафика, поэтому внешний cron каждые 10 минут дёргает `/tick`.
  Это будит сервис, и при первом тике после 8:00 бот шлёт сводку (один раз в день).

## Развёртывание
1. **Токен**: в Telegram напиши @BotFather, `/newbot`, сохрани токен.
2. **База**: создай бесплатную Postgres-базу (например, на neon.tech) и скопируй строку подключения (`postgresql://...`).
3. **GitHub**: залей эту папку в новый репозиторий (файл `.env` не заливай).
4. **Render**: New → Web Service → выбери репозиторий.
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `uvicorn main:api --host 0.0.0.0 --port $PORT`
   - Instance Type: Free
   - Environment: `BOT_TOKEN`, `DATABASE_URL`, `CRON_SECRET` (любая длинная случайная строка)
5. **OWNER_ID**: когда сервис запустится, напиши боту `/start`. Он ответит твоим Telegram id.
   Добавь его в переменную `OWNER_ID` на Render (сервис перезапустится). После этого бот отвечает только тебе.
6. **Cron**: на cron-job.org создай задачу, которая каждые 10 минут открывает
   `https://ИМЯ-СЕРВИСА.onrender.com/tick?key=ТВОЙ_CRON_SECRET`.
7. **Проверка**: напиши боту `завтра тест`, потом `/morning`. Сводку по cron можно проверить так:
   `.../tick?key=...&force=1` (шлёт сразу, без проверки времени).

## Расписание универа
Заполни словарь `SCHEDULE` в `schedule.py` (пример внутри файла).

## Переменные окружения
| Имя | Зачем |
|---|---|
| BOT_TOKEN | токен от BotFather |
| DATABASE_URL | строка подключения к Postgres |
| CRON_SECRET | секрет для `/tick` |
| OWNER_ID | твой Telegram id |
| MORNING_HOUR | час сводки по Астане (по умолчанию 8) |
